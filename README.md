# 수학쑥쑥 · 초등 4학년 2학기

분수·삼각형·소수·사각형을 배우는 모바일 웹 학습 앱입니다. 산에서 찍은 사진 속 아이와 블록 캐릭터가 어깨동무하는 환영 이미지를 첫 화면에 배치했습니다. 배경은 은은한 블록 풍경을 유지하고 단원 선택과 문제 풀이 영역은 읽기 편하게 구성했습니다.

- 1단원 분수의 덧셈과 뺄셈
- 2단원 삼각형
- 3단원 소수의 덧셈과 뺄셈
- 4단원 사각형: 수직과 평행 포함

단원마다 기본형 32개, 응용형 24개, 서술형·문장제 24개로 총 320문제입니다. 문제마다 힌트 2단계와 단계별 풀이를 제공합니다. 서술형은 이야기로 주어진 조건을 읽고 수를 입력하거나 보기를 고르는 문장제이며, 장문 답안이나 자기 채점은 사용하지 않습니다.

분수는 자연수·분자·분모 칸으로 입력합니다. 값이 같은 대분수·가분수·약분 전후 분수를 정답으로 인정합니다. 소수는 소수점으로 입력하고 정확한 유리수 비교로 채점합니다. 첫 화면의 큰 단원 카드를 누르고 기본형·응용형·서술형·문장제 또는 골고루 풀기를 누르면 바로 10문제를 시작합니다. 단원 선택 드롭다운은 사용하지 않습니다. 핵심 개념과 개별 문제 목록은 필요할 때 별도로 볼 수 있습니다. 전체 단원을 섞는 연습도 가능합니다. 오답 노트와 기록은 이 브라우저에 저장됩니다.

320문제로 확장하면서 기존 192문제의 ID·내용과 현재 교과 과정의 기록 키를 유지했습니다. 이미 푼 문제의 기록은 이어집니다. 이전의 도형 전용 과정 기록은 이 교과 과정과 구분됩니다. 로그인이나 서버 데이터베이스 없이 GitHub Pages에서 동작하며, 첫 방문 후 필요한 자료를 캐시해 오프라인 학습을 지원합니다.

## 학습 범위와 참고

EBSMath 학년별 교과, 아이스크림미디어 2022 개정 수학 4-2 공개 지도 자료의 단원 구성, 학교 공개 성취기준을 참고하여 문제·힌트·풀이를 새로 작성했습니다. 원문 문제나 이미지를 복제하지 않았습니다.

- [EBSMath 전체 교과](https://www.ebsmath.co.kr/siteMap)
- [아이스크림 수학 4-2](https://qrd.i-scream.co.kr/22USB/22MA402/index.html)
- [송내초 4학년 2학기 평가계획](https://www.goebc.kr/upload/songnae-e/na/bbs_970/2025/09/A959D40B-8FC7-85C9-D2FF-06BB0257BB8C.pdf)

분수는 동분모 계산만, 소수 덧셈·뺄셈은 소수 두 자리까지 다룹니다. 소수 세 자리 수는 자릿값과 크기 비교에서만 다룹니다. 넓이 공식·통분·분수 곱셈 등 후속 학년 내용은 포함하지 않습니다.
