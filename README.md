# 도형쑥쑥 · shape-garden

초등학교 4학년을 위한 도형 학습 웹앱입니다. 휴대폰, 태블릿, PC 브라우저에서 사용할 수 있습니다.

- 6개 단원: 각도, 평면도형의 이동, 삼각형, 수직과 평행, 사각형, 다각형
- 핵심 개념 26개와 연습문제 117개
- 객관식·숫자 입력, 작은 힌트, 정답 및 단계별 풀이
- 오늘의 10문제, 단원별 8문제, 오답 복습
- 각도 슬라이더, 평면도형 이동 실험실
- 학습 기록은 사용하는 브라우저에 저장되며 다른 기기와 자동으로 공유되지 않습니다.

## GitHub Pages 자동 게시

저장소 Settings → Pages → Build and deployment에서 Source를 Deploy from a branch, Branch를 main, 폴더를 /(root)로 지정하고 Save를 누릅니다.

설정 후 main 브랜치의 파일을 변경하면 GitHub가 자동으로 게시합니다. 접속 주소는 GitHub Pages 설정 화면에 표시됩니다.

별도 빌드, 서버 설치, API 키가 필요하지 않습니다. 모든 학습 내용은 이 저장소의 정적 파일로 제공됩니다. 최초 접속에는 인터넷이 필요하며, 서비스 워커 캐시가 준비된 뒤에는 저장된 화면을 오프라인으로 이용할 수 있습니다.

브라우저 데이터 삭제 또는 시크릿 모드 종료 시 학습 기록이 지워질 수 있습니다. 앱 자체는 학생 이름·전화번호·이메일을 요구하지 않습니다.

문제와 풀이는 직접 작성한 연습용 콘텐츠이며, 특정 교과서의 수록 문제를 복제하지 않았습니다. 교과서에 따라 단원 순서는 다를 수 있습니다.
